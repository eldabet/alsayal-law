# موقع مكتب راكان بن ماجد السيال للمحاماة والاستشارات القانونية

موقع تعريفي من صفحة واحدة، منشور عبر GitHub Pages، ومبني على دليل الهوية البصرية للمكتب
(الأخضر الغامق `#022B22` والذهبي `#CE9F3A`).

- `index.html` الصفحة كاملة. الشعار مضمّن داخلها كرسم متجهي (SVG)، والخط من Google Fonts.
- `assets/` ملفات الشعار (ملوّن وأبيض، كامل ورمز)، وأيقونة المتصفح، وصورة المشاركة في وسائل التواصل.
